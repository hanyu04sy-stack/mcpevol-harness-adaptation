# Selective Patch Harness

Member C places the Selective-patch harness knowledge in this directory. Before running it, add `system_prompt.md`, `tool_usage_rules.md`, and `manifest.json` with the same contract as `harness/original/`.

Only knowledge affected by detected tool-schema changes should be updated. Do not modify the benchmark checkout, fixed task set, model settings, judge settings, or MCP version mapping.
